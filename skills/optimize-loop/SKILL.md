# 엔진 개선 루프 (엔진 세션)

## 지키는 것
- engine/과 notes/engine.md만 고친다. 화면 코드 · PLAN.md · SVG는 고치지 않는다(AGENTS.md "두 세션").
- 출력은 SPEC.md "엔진 입출력 계약" 형식 그대로. 계약을 바꿔야 하면 멈추고 묻고, 바꾸면 SPEC · stub_output.json · DECISIONS를 함께 고친 뒤 progress에 `[엔진] 계약 바뀜: …` 한 줄.
- 표준 라이브러리 우선. 새 패키지는 허락 뒤에만.
- 위반이 0이 아니면 지표가 좋아도 채택하지 않는다.

## 1. 평가 스크립트 먼저 (engine/evaluate.py)
- 엔진 출력 JSON과 입력만 받아 **처음부터 다시 센다.** 엔진이 스스로 계산해 넣은 지표는 읽지 않는다.
- 출력 한 줄: `파일 · 위반 N(조건별) · 비교 기준 1 · 2 · … · 실행 시간 s`. 데이터 파일이 여러 개면 파일마다 한 줄 + 합계 한 줄.
- 실행 예: `python engine/evaluate.py data/*.json` (엔진을 불러 시간까지 재거나, `--output out.json`으로 출력만 채점).
- 검증: 손으로 만든 작은 입력 하나에서 위반이 있는 출력과 없는 출력을 넣어 위반 수가 맞게 나오는지 assert 하나로 확인한다.

## 2. 가장 단순한 기준안 → 이식 요청
- 탐욕(앞에서부터 되는 대로 배정) · 정렬 한 번 같은 가장 단순한 방법으로 `solve(input)`을 만든다. 위반 0이 먼저다.
- 평가를 돌리고, notes/progress.md 맨 아래에 `[엔진] 엔진 v1 준비 · python engine/evaluate.py … → 위반 0 · 지표 … · 시각`.
- 언제 끝나도 돌아가는 제출물이 먼저다. 화면 세션이 이 줄을 보고 이식한다.

## 3. 개선: 한 번에 하나
1. 바꿀 것 하나를 정한다(이유: 지금 지표에서 무엇이 나쁜지).
2. 바꾸고 → 모든 데이터로 평가 → 이전 결과와 나란히 비교.
3. 비교 기준을 **우선순위 순서로** 본다: 앞 기준이 나빠졌으면 뒤가 좋아도 되돌린다. 앞이 같을 때만 다음 기준.
4. 나아졌으면 채택, 아니면 `git checkout -- engine/` 대신 바꾼 부분만 손으로 되돌린다(내 다른 변경을 지우지 않게).
5. 채택이든 되돌림이든 DECISIONS.md 맨 아래에 한 줄: `[엔진] 바꾼 것 / 전후 숫자 / 버린 대안 / 출처`.
6. 채택해서 버전이 오르면 progress에 `[엔진] 엔진 vN 준비 · 명령 → 숫자 · 시각`.

## 4. 지키는 판단
- 데이터가 여러 개면 모두로 평가한다. 한 파일에서만 나아지고 다른 파일이 나빠지면 채택하지 않는다(한 파일에 맞춘 규칙 금지).
- 실행 시간도 매번 기록한다. SPEC의 시간 한도를 넘으면 위반으로 센다.
- 같은 아이디어가 두 번 실패하면 멈추고 보고한다: 시도 · 숫자 · 다음 후보 2개 · 추천.

## 4-1. 멈추는 때 (루프가 끝없이 돌지 않게)
- **개선이 멈춤**: 연속 3번 채택이 없으면(아이디어가 같든 다르든) 멈추고 보고한다: 마지막 채택 버전 · 숫자 · 다음 후보 2개 · 추천. 계속할지는 내가 정한다.
- **횟수 한도**: 시도 8번마다 멈추고 지금까지의 표(버전 · 바꾼 것 · 위반 · 지표 · 시간 · 채택/되돌림)를 보여 준 뒤 계속할지 묻는다.
- **실행 한도**: 평가는 늘 시간 제한을 걸어 돌린다: `timeout <초> python engine/evaluate.py …`. 초 = SPEC 시간 한도 × 데이터 파일 수 × 2 (한도가 없으면 파일당 60초). `timeout` 명령이 없으면 evaluate.py 안에서 `signal.alarm`으로 끊는다. 넘으면 그 시도는 위반으로 보고 되돌리며, 연속 3번 세기에 넣는다.
- notes/engine.md에 시도 기록을 짧게 남긴다(버전 · 바꾼 것 · 숫자). 20줄 넘는 설명도 여기에.

## 5. 보고 (단위마다 3줄)
- 바꾼 것, 전후 숫자(명령 포함), 채택 · 되돌림. 그리고 다음 개선으로 간다(멈춤 조건이 아니면 기다리지 않는다).
